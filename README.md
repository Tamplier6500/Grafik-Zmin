# Графік змін (v1.7.0)

Автономний PWA-додаток для обліку змінного графіка (Зміни А, Б, В, Г, Д + власна колонка графіка), подій, іспитів (`ОП`, `ПБ`, `ПТЕ`, `НПАОП`, `РБ`, `ПНЯРБ`), додаткових днів (`Д`) та днів народження.

## Керування
- **Коротке натискання** на рядок дня або дати — виділення рядка.
- **Подвійний тап або утримання (400 мс)** на дату — відкриття вікна дати (екзамени, примітки, дні народження).
- **Подвійний тап або утримання (400 мс)** на клітинку зміни — зміна значення на день, позначка `Д` або примітка.
- **Додаткова колонка (Мій графік)** — вмикається в «Налаштування порядку змін», за замовчуванням показує `Р` (Пн–Пт) та `-` (Сб–Нд), редагується під себе.

## Файли проєкту
- `index.html` — головний файл додатку
- `version.json` — маркер актуальної версії для перевірки оновлень
- `manifest.json` — маніфест PWA
- `sw.js` — Service Worker (`shift-schedule-v10`)
- `icon-192.png`, `icon-512.png` — іконки додатку

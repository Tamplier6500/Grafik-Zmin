# Графік змін (PWA)

Автономний веб-додаток для обліку змінного графіка (Зміни А, Б, В, Г, Д), подій, іспитів (`ОП`, `ПБ`, `ПТЕ`, `НПАОП`, `РБ`, `ПНЯРБ`), додаткових днів (`Д`) та днів народження з Excel.

## Файли проєкту
- `index.html` — головний файл додатку
- `manifest.json` — маніфест PWA для встановлення на головний екран Android / iOS / ПК
- `sw.js` — Service Worker для офлайн-роботи
- `icon-192.png` — іконка додатку 192×192
- `icon-512.png` — іконка додатку 512×512

## Розгортання на GitHub Pages або Vercel
1. Завантажте всі 5 файлів у корінь репозиторію GitHub.
2. У налаштуваннях репозиторію (**Settings → Pages**) оберіть гілку `main` та папку `/ (root)` — або імпортуйте репозиторій у **Vercel**.
3. Відкрийте отримане `https://` посилання у Chrome (Android) або Safari (iOS) та натисніть **«Додати на головний екран»**.

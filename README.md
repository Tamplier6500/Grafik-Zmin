# Графік змін (PWA)

Автономний веб-додаток для обліку змінного графіка (Зміни А, Б, В, Г, Д), подій, іспитів (`ОП`, `ПБ`, `ПТЕ`, `НПАОП`, `РБ`, `ПНЯРБ`), додаткових днів (`Д`) та днів народження.

## Керування
- **Коротке натискання** на рядок дня або дати — виділення рядка.
- **Тривале натискання (утримання)** на дату — відкриття вікна дати (екзамени, події, дні народження).
- **Тривале натискання (утримання)** на клітинку зміни — зміна номера зміни, позначка `Д` або примітка.

## Файли проєкту
- `index.html` — головний файл додатку
- `manifest.json` — маніфест PWA
- `sw.js` — Service Worker (`shift-schedule-v9`)
- `icon-192.png`, `icon-512.png` — іконки додатку
